# Tracking insights

The tracker editor does not expose the former optional **What are you tracking?** description field. Existing stored descriptions remain intact when another tracker setting is edited.

Number and duration trackers can define an optional target, goal direction, and per-day or weekly tracking window. Attaching one target tracker to a scheduled Tracking task keeps the familiar quantitative task card, Quick log, amount logger, duration timer, lock action, reminders, and schedule while the tracker remains the single source for its definition and values. A number tracker can also use **Health Connect steps** as its source once Health Connect is connected in Settings; its synced steps and any manually added value are stored as tracker entries.

Tracker task goals are versioned by local calendar date. Changing a number or duration target, goal direction, or tracking window updates the goal for today and later dates without rewriting the target used to calculate or display earlier task days. Saving another change on the same date replaces that date's version.

For manual event, number, rating, and duration trackers, the optional unit or scale label uses a predefined list, including minutes and hours for time-based values. The selected label is preserved when reopening an existing tracker; the measurement-type default applies only when the user changes that type. Duration log and target fields use the selected time unit, converting minutes or hours to the seconds stored internally, and insights convert those seconds back to the selected unit. Because this conversion does not reinterpret stored values, any existing duration tracker with logs can still select minutes or hours while its other measurement settings remain locked, including when correcting a legacy blank or inconsistent unit. Ratings include one **Out of min–max** option that follows their current scale bounds. Choosing **Custom** vertically expands a free-text label field, and existing custom labels continue to use that field when edited. When no unit or scale label is selected, the field displays **None**.

Every numeric tracker setting uses the shared tap-first number-pad field: rating scale bounds and optional task targets are shown as value buttons with a compact title above the value. Opening a field shows its current value as a muted placeholder; the value changes only after new keypad input is confirmed.

Number and duration logs use that same shared number-pad button, so entering a logged value does not open the device keyboard. Choosing **Log entry** from a number or duration tracker on the main Tracking page opens that number pad immediately.

Saved trackers support an emoji icon selected from the searchable virtual list above the color picker. The chosen icon is preserved through offline saves and appears on tracker cards, logs, task attachments, and journal contexts; tracker cards use the standard tracker icon when no custom icon is selected, and existing Material icons remain supported.

The tracker editor uses one archive/restore action in place of direct deletion. For an active or paused tracker, the action asks whether to archive it or delete it permanently. Archiving removes the tracker from logging, charts, and new attachment choices while preserving its definition, active or paused state, and logs. Archived trackers appear in the collapsible Archive section and can be opened to restore or permanently delete. Permanent deletion removes the tracker and all of its logs.

The factor selector groups device-derived wellbeing data under **Health Connect**. Tracker entries in both the factor and outcome selectors display their selected icon and color, with the standard tracker icon as a fallback. Task, interval, and Review set factors also display their selected icon and color, falling back to their attached content or content type icon. Steps are read as daily aggregates from Health Connect. Screen time is measured from Android screen-interactive usage events and requires Usage Access because Health Connect does not define a screen-time record.

Both device factors are quantitative. Insights load one value per local calendar day in the selected range, use `steps` and `minutes` as their respective units, and refresh the current day's cached value after one minute. The current day's screen-time range ends at the current instant so an ongoing interactive session never counts future time through midnight.

When Android Usage Access is enabled, the main Tracking page also loads screen time for the visible week and shows it as a duration series in the weekly chart. Future dates are not requested. Like tracker series, screen time can be hidden or restored from the chart legend. The weekly chart mounts only once it has a tracker or screen-time series, so an empty chart does not appear during route navigation.

The main Tracking page lists the outcome group (**How you felt**) above the factor group (**Things you did**) and keeps tracker cards focused on starting a new log and managing the tracker. The tracker action menu offers **Log entry** and **Edit**; Pause/Unpause, Write reflection, and View reflections are no longer offered. Cards with an entry on the selected date are greyed out while preserving their tracker icon, and remain available for additional entries and tracker actions. Each empty tracker group, the no-trackers view, and days without entries use the shared empty-state card. Entries for the selected date appear together in a chronological **Log** section below both tracker groups. Selecting a log opens it for editing.

Archived trackers, tasks, intervals, and Review sets are excluded from the factor and outcome selectors. Their historical logs remain available elsewhere in the application.

Swiping left across the weekly chart advances its visible range by one week, while swiping right returns one week. The graph's inner plot moves in horizontally from the navigation direction as the week changes, while its tooltip and series selector stay in place. Swiping left across **Things you did**, **How you felt**, or the **Log** section advances to the next date, while swiping right returns to the previous date. The three day-dependent sections move in together from the navigation direction with a quick horizontal transition, and a centered card briefly confirms the selected date before fading away.

Tracker cards can be reordered within their **Things you did** or **How you felt** group by pressing and holding, then dragging. Cards animate into their prospective grid positions while dragging, with row-aware targeting for stable vertical movement across the grid. The new order is applied immediately and saved through the offline-first data layer; if persistence fails, the previous order is restored and an error is shown.

The weekly chart uses the full SVG width without a horizontal plot inset. Number and duration trackers, including device screen time, appear as lines; ratings, events, and yes/no trackers remain grouped bars. Each line uses its visible-week and connected boundary values to retain a useful vertical range, and it connects logged points across days without a value. The chart also loads adjacent-week context and clips a line at the visible edge when its nearest preceding or following value falls outside the selected week. The Insights timeline likewise connects each factor and outcome series across dates where that series has no value. Insight axes use configured bounds only for fixed-scale ratings and yes/no trackers; ordinary numbers such as weight use their observed range. Decimal tick labels keep changes narrower than one unit distinguishable, while wider ranges retain whole-number labels. The weekly chart keeps its grid, day labels, and chart-series multi-select visible while a week is loading instead of replacing the chart with a skeleton. Hovering, touching, or using the keyboard to inspect a day shows that day's active-series values in an opaque tooltip above the graph. The tooltip stays on the opposite horizontal side from the inspected day so it does not cover that day's data, and fades out three seconds after the latest interaction. The series selector is reserved for choosing visible series and does not repeat daily values. Its list groups outcome trackers under **How you felt** and factor trackers, including device screen time, under **Things you did**. When the selected week has no entries, its empty state appears above the series selector. The compact selector has no entrance transition, shows each tracker's icon alongside its series color and shape in the dense list and x-small tonal selected chips, displays at most four selected series, and summarizes the remainder as an overflow count. When loading finishes, bars animate up from the baseline and lines fade in; devices that request reduced motion receive the final state immediately.
